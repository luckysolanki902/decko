# Phase 7 — HTTP APIs with the Standard Library

**Days 31–35 · Outcome:** build a production-shaped API with `net/http` before reaching for a framework.

- Day 31: HTTP semantics, the request/response lifecycle, method-aware routing, handlers, headers, response commitment, and server timeouts.
- Day 32: bounded JSON decoding, unknown-field rejection, transport models, validation, problem responses, status codes, and idempotency.
- Day 33: middleware composition, recovery, structured logging, request IDs, redaction, CORS, rate-limit placement, and proxy trust.
- Day 34: configured HTTP clients, connection reuse, outbound context, signals, graceful shutdown, draining, health, and readiness.
- Day 35: build a Community Tool Library API with tool, member, loan, return, and maintenance transitions; a privacy-safe public catalog; explicit server limits; request tracing; `httptest`; graceful shutdown; and OpenAPI documentation.
