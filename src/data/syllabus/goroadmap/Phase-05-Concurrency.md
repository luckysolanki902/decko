# Phase 5 — Concurrency, Channels & Context

**Days 21–25 · Outcome:** build concurrent software with explicit lifetime, ownership, cancellation, and failure behavior.

- Day 21: concurrency versus parallelism, goroutines, scheduler intuition, lifecycle ownership, leaks, and `WaitGroup` rules.
- Day 22: unbuffered and buffered channels, synchronization, backpressure, close ownership, direction types, ranges, and deadlocks.
- Day 23: `select`, timers, tickers, deadlines, context cancellation, propagation, cancellation-aware loops, and partial results.
- Day 24: data races, logical races, mutexes, read/write locks, atomics, lock scope, and the race detector.
- Day 25: build a Parallel Archive Verifier with bounded hashing workers and open files, prompt whole-run cancellation, progress events, deterministic mismatch reports, partial-result accounting, leak checks, throughput evidence, and race-clean tests.
