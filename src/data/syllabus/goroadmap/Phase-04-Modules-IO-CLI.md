# Phase 4 — Packages, Modules, I/O & CLI Engineering

**Days 16–20 · Outcome:** organize a maintainable module and ship reliable file- and network-facing commands.

- Day 16: packages, exported API design, modules, `go.mod`, `go.sum`, minimal version selection, `cmd`, `internal`, documentation, and package cycles.
- Day 17: `io.Reader`, `io.Writer`, files, buffered I/O, scanner limits, paths, permissions, atomic writes, and cleanup.
- Day 18: JSON encoding/decoding, tags, optional fields, unknown fields, streams, validation, and transport/domain separation.
- Day 19: flags, subcommands, configuration precedence, environment variables, exit codes, signals, stdout/stderr contracts, and CLI errors.
- Day 20: build an installable Research Archive Catalog CLI with streaming file inspection, deterministic versioned JSON, sidecar-metadata validation, duplicate and drift reports, atomic writes, cancellation, and distinct scripting-friendly exit codes.
