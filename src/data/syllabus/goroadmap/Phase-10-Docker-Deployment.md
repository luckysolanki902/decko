# Phase 10 — Docker, Compose & Deployment

**Days 46–50 · Outcome:** package, run, secure, automate, and deploy a Go service only after its runtime behavior is understood.

- Day 46: container, image, layer, registry, namespace/cgroup, Dockerfile, build context, cache, `docker build`, and `docker run` mental models.
- Day 47: multi-stage Go builds, static binaries, minimal images, non-root users, signals, configuration, secrets, and image inspection.
- Day 48: Compose services, networks, volumes, PostgreSQL and Redis dependencies, health checks, startup versus readiness, migrations, and local parity.
- Day 49: CI test/build/scan flow, immutable tags and digests, registries, deployment configuration, resource limits, smoke tests, rollback, and evidence.
- Day 50: ship a Deployed Watershed Operations Stack with separate non-root API and worker images, healthy PostgreSQL/Redis Compose dependencies, automated test and scan gates, immutable registry digests, cold-start and dependency-restart evidence, backup restoration, deployment, rollback, and a runbook.
