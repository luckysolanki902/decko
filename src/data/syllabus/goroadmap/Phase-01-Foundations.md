# Phase 1 — Go Foundations & Toolchain

**Days 1–5 · Outcome:** compile, format, test, and reason about small Go programs without relying on copied syntax.

- Day 1: Go's design goals, Go 1.26 toolchain, packages, imports, `main`, `go run`, `go build`, `gofmt`, and compiler feedback.
- Day 2: declarations, zero values, primitive types, strings/bytes/runes, constants, conversion, overflow, and `fmt` formatting.
- Day 3: `if`, lexical scope, every useful `for` form, `switch`, early returns, and readable branching.
- Day 4: function signatures, multiple returns, variadic and first-class functions, `defer`, and cleanup order.
- Day 5: build a Trail Ration Planner CLI for volunteer trek leaders, using gram-based integer arithmetic, explicit package and reserve policies, impossible-plan validation, pure calculations, boundary tests, and a useful README.
