# Phase 3 — Structs, Methods, Interfaces & Generics

**Days 11–15 · Outcome:** design small APIs with composition, explicit invariants, narrow interfaces, useful errors, and restrained generics.

- Day 11: structs, literals, visibility, zero-value design, embedding, constructor functions, and invariant ownership.
- Day 12: methods, method sets, value versus pointer receivers, copying, mutation, and receiver consistency.
- Day 13: implicit interface satisfaction, consumer-owned interfaces, dynamic types, nil-interface traps, assertions, and type switches.
- Day 14: errors as values, wrapping, `errors.Is`, `errors.As`, sentinel and typed errors, panic, and recovery boundaries.
- Day 15: build a Multi-Source Habitat Importer whose ranger CSV, sensor JSON, and hand-entered text sources share a narrow consumer-owned interface, preserve row-level error context, produce an explicit partial-import report, and accept a new format without orchestration changes.
