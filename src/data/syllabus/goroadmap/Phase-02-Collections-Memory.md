# Phase 2 — Collections, Memory & Functional Building Blocks

**Days 6–10 · Outcome:** transform real data while explaining exactly what is copied, shared, or allocated.

- Day 6: arrays, slice headers, backing arrays, length/capacity, `append`, aliasing, `copy`, and nil versus empty slices.
- Day 7: maps, comma-ok lookup, deletion, nil-map behavior, set patterns, and deterministic sorted output.
- Day 8: UTF-8, byte length versus rune count, `range` decoding, builders, Unicode-safe operations, and normalization awareness.
- Day 9: addresses, dereferencing, nil pointers, pass-by-value, reference-like descriptors, and practical escape intuition.
- Day 10: build a bounded-memory Field Sensor Stream Summarizer with station coverage and range statistics, stable anomaly rankings, a rejected-record report, Unicode-safe labels, tests, and benchmarks.
