# React Native Roadmap — Overview

This 57-day course targets stable React Native 0.86, Expo SDK 57, React 19.2.3, Node 22.13+, TypeScript, Hermes V1, and the New Architecture. It uses npm throughout and teaches Expo Go only as the first feedback loop; development builds arrive before any custom native capability.

| Phase | Days | Focus | Portfolio project |
|---|---:|---|---|
| 1 | 1–5 | Native mental model, Expo, core UI, interaction | Pocket Plant Care Board |
| 2 | 6–11 | Layout, styling, lists, forms, accessibility | Community Recipe Exchange |
| 3 | 12–16 | Expo Router, links, tabs, auth architecture | Local League Matchday |
| 4 | 17–22 | Fetch, Redux Toolkit, forms, offline sync | Cooperative Pantry Ledger |
| 5 | 23–28 | Permissions, camera, location, notifications | Neighborhood Tree Walk |
| 6 | 29–34 | Motion, gestures, performance, accessibility | Choreography Cue Composer |
| 7 | 35–39 | Tests, debugging, security, privacy | Youth Club Consent Desk |
| 8 | 40–47 | Android Studio, ADB, Gradle, Xcode, CocoaPods, widgets, native modules | Quiet Space Signal |
| 9 | 48–52 | EAS, signing, updates, stores, observability | Indie Cinema Release Train |
| 10 | 53–57 | Integrated final capstone | Lantern Live Festival Companion |

Every phase ends with a distinct project for a named user and decision. Project completion requires degraded-mode behavior, evidence of correctness, one changed requirement for transfer, and an explicit non-goal—not merely a polished happy-path demo. Every authored lecture follows the deck contract: mental model, escalating examples, platform failures, hands-on work, common mistakes, 30+ practice reps, quick checks, and a ten-question final quiz.
