# Phase 2 — Layout, Styling & Responsive Mobile UI

**Days 6–11 · Outcome:** create interfaces that survive small screens, tablets, dark mode, large text, keyboards, and long lists.

- Day 6: Yoga, mobile Flexbox defaults, axes, growth, compression, gap, intrinsic size, measurement, and overflow debugging.
- Day 7: `StyleSheet`, style arrays, tokens, semantic themes, dark mode, dynamic type, contrast, elevation, and platform shadows.
- Day 8: bundled/remote images, sizing, aspect ratios, placeholders, caching awareness, icons, and responsive media.
- Day 9: `ScrollView` versus `FlatList`/`SectionList`, virtualization, stable keys, pagination, loading, empty, failure, refresh, and retry.
- Day 10: `TextInput`, focus, keyboard avoidance, autofill, validation, announcements, selections, dates, drafts, and submit UX.
- Day 11: build the Community Recipe Exchange for a cooking club choosing recipes by time and dietary constraint. Use a 300-record sectioned catalogue, search, filters, a keyboard-safe contribution form, semantic themes, dynamic type, and phone/tablet layouts. Audit long content, contrast, screen readers, and the largest supported font scale; transfer the layout to a compact landscape comparison view. Accounts, APIs, ratings, delivery, and persistence stay out of scope.
