# Phase 8 — Native Toolchains, Widgets & Custom Capabilities

**Days 40–47 · Outcome:** understand and debug both native build systems before crossing into Swift/Kotlin or shipping platform extensions.

- Day 40: Android Studio, SDK Manager, JDK, AVD/emulator configuration, ADB devices/install/shell/reverse/files/permissions/deep links, logcat, crashes, and ANRs.
- Day 41: Gradle wrapper, settings, plugins, repositories, tasks, variants, flavors, manifests, signing, R8/ProGuard, APK/AAB inspection, caches, and CI failures.
- Day 42: Xcode projects/workspaces, schemes, targets, build settings, Simulator, physical devices, Instruments, signing, entitlements, DerivedData, archives, and symbols.
- Day 43: CocoaPods Podfile/podspec/lockfile/workspace, frameworks, headers, deployment targets, architecture slices, SPM awareness, linker failures, and reproducible installs.
- Day 44: Expo Go versus development builds, Continuous Native Generation, prebuild ownership, app config, config plugins, mods, idempotency, rebuild triggers, and local/EAS builds.
- Day 45: Android App Widgets, iOS WidgetKit, timelines, refresh budgets, shared storage, deep links, stale UX, Live Activities, Dynamic Island, extensions, and testing.
- Day 46: Expo Modules API, JSI-era boundaries, threads, functions, events, views, matching Swift/Kotlin contracts, native UI, tests, and brownfield decisions.
- Day 47: build Quiet Space Signal, which classifies short on-device ambient samples into quiet, moderate, or loud bands without retaining audio. Implement equivalent Swift/Kotlin module contracts, typed events, lifecycle cleanup, shared summaries, Android/iOS widgets, stale labels, deep links, and an idempotent config plugin. Prove development and archive builds through ADB, logcat, Gradle, Xcode, and CocoaPods, then migrate a native threshold preference. Recording, speech recognition, surveillance, medical claims, and continuous background sampling stay out of scope.
