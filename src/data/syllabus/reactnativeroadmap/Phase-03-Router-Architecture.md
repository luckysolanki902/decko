# Phase 3 — Expo Router & Application Architecture

**Days 12–16 · Outcome:** design deep-linkable navigation with scalable feature boundaries.

- Day 12: `src/app`, index and layout conventions, stacks, `Link`, router actions, route groups, URLs, and typed routes.
- Day 13: dynamic segments, parameters, serialization, app schemes, universal links, cold starts, invalid IDs, and not-found recovery.
- Day 14: native tabs, nested layouts, stacks, modals, gestures, state preservation, and platform back behavior.
- Day 15: session hydration, protected routes, redirects, expired sessions, provider placement, feature folders, and dependency direction.
- Day 16: build Local League Matchday for supporters choosing a fixture, venue, and followed club. Use typed identifier-only routes, tabs, nested stacks, a result-report modal, mock member gates, and invalid-ID recovery. Prove cold/warm links, restored destinations, browser and Android back behavior, then add a postponed-fixture route reached from two entry points. Live scores, payments, real authentication, and fetching stay out of scope.
