# Phase 1 — Mobile Foundations & Modern Expo

**Days 1–5 · Outcome:** explain the native render path and ship a typed, accessible app to Android and iOS.

- Day 1: native views versus DOM; React Native 0.86; Expo SDK 57; Node 22; npm; Metro; Hermes V1; Expo Go; DevTools; physical-device workflow.
- Day 2: `View`, `Text`, `Image`, `ScrollView`, `Pressable`; typed props; children; composition; native text and image rules.
- Day 3: state snapshots, press events, controlled input, keyboard behavior, touch targets, feedback, state ownership, and derived values.
- Day 4: platform differences, Android edge-to-edge, safe areas, platform files, inspector, logs, and version-mismatch debugging.
- Day 5: build the Pocket Plant Care Board for a housemate deciding what needs care today. Model due, completed, skipped, and undone state; derive progress; prove accessible interactions and safe-area layouts on Android and iOS; then transfer the design by adding a second care action without duplicating state. Reminders, cloud sync, diagnosis, and sensor data stay out of scope.
