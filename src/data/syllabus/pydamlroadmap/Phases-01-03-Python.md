# Phases 1–3 — Python for Analytical Work

## Phase 1 · Days 1–12 · Python & Exploratory Analysis Foundations

The analyst loop and first dataset; values and business arithmetic; conditions; lists; dictionaries; messy strings; aggregation loops; functions; safe CSV reading; summaries; evidence charts; **Neighbourhood Cooling-Centre Access Brief**.

The gate requires explicit grain, checked ingestion, assertions, a table and two decision-specific charts, a bounded recommendation, and transfer to a changed neighbourhood requirement.

## Phase 2 · Days 13–24 · Python Problem Solving & Program Design

Tuples and sets; readable comprehensions; function contracts; scope and closures; modules and packages; tests; iterators and generators; sorting and ranking; dates and reporting periods; decimal money; command-line utilities; **Community Pantry Stock Reconciliation**.

The gate requires validated record contracts, unit-aware matching, duplicate and missing-ID tests, deterministic ranking, an operator runbook, and transfer to changed package sizes.

## Phase 3 · Days 25–36 · Files, Errors, OOP & Reproducible Workflows

Text/bytes, CSV and JSON boundaries; safe paths; exceptions; logging; configuration and environments; classes; dataclasses; composition and protocols; context managers; bounded regex; auditable pipeline stages; **Archive Condition Survey Pipeline**.

The gate requires quarantine of invalid inputs, specific failures, tested domain rules, manifests and run IDs, a preservation brief, and a recovery drill.
