# Course Guidelines

These files hold the detailed authoring rules for each roadmap. `AGENTS.md` routes here so the main instruction file stays small.

- `teaching-method.md` - **how to explain, all roadmaps. Read before the roadmap file below.**
- `da.md` - DAML / data analytics lectures
- `ml.md` - ML, DL, NLP, LLM, RAG, agents, diffusion, MLOps
- `webd.md` - WebD HTML lectures and practice-heavy web lessons
- `dsa.md` - DSA (C++) lectures, discovery-first pedagogy, competitive-programming roadmap
- `course-data.md` - phase data, roadmap metadata, and syllabus sync
- `lecture-generation.md` - next-three-lectures workflow and batch handoff
- `quiz-blocks.md` - quiz JSON and answer-writing contract
- `deck-chapters.md` - headings that define reader chapters
- `revision.md` - retrieval practice and pre-authored revision sets
- `go.md` - Go lectures and backend development
- `legacy-daml-style.md` - legacy DAML structure; teaching-method rules take precedence

Research lives in [docs/research/](../docs/README.md). Course study systems and batch
handoffs remain beside their syllabi in `src/data/syllabus/`.
